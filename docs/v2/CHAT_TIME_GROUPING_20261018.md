# 对话时间分组与访客上下文（2026-10-18）

- 时间标记采用首条、相邻消息间隔至少5分钟或跨天时显示；居中弱化文字，不增加逐条时间行。今天时分、昨天加昨天、更早显示日期，跨年加年份。5分钟是产品选定规则，不声称为微信官方算法。
- 普通历史保存原始时间，刷新不重打时间；旧记录缺少时间不补造。精确时间可悬停查看。时间分组不改变模型上下文。
- 访客关闭通过独立接口封存后台记录、拒绝继续使用该会话、取消正在生成的请求；普通历史不含访客。关闭通知为浏览器尽力发送，非硬性内存清零保证；常驻模型权重不卸载。
- 请求禁用持久提示缓存，实际效果依模型服务能力；仍按会话组织当前请求上下文。
- 按用户明确要求只将页面显示名改为Qwen3.8；实际模型身份沿用服务返回值，悬停可见，不声称已更换模型。

验证：27项针对性测试通过，覆盖HTTP关闭入口、后台档案保留、关闭后拒绝续用、取消生成、原有前端生命周期与公网隔离。真实浏览器5条消息形成3组，刷新时间一致，390宽无横向溢出；真实访客问答关闭200，后台两条消息保留。
