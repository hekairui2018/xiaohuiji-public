# 数字型号候选与上下文纠正

修正数字简称未作为型号线索时，检索泛化到其他产品手册并被直接交付的问题。文件工具从已有登记型号及文件封面型号找数字段一致的候选，保留英文前后缀，所有候选标记身份未确认；不把数字相近或无关产品当命中。当前数字简称按3至5位查找，带像素/尺寸等已识别单位的不作为型号候选；不能据此承诺全部自然语言与芯片角色都已正确识别。

候选交给模型选取资料，快捷交付也保留“您说的是候选型号吧？如果不对请补充”开场，不等待确认才给资料。小机器人提供登记候选按钮，点击后只把“上面说的712改成R712S，继续查刚才的资料”这类普通纠正语句填入输入框，不自动发送、不写第二份型号状态、不绑定选型算法。用户可编辑，发送后由模型使用同一会话历史理解纠正目标。

生成期间允许编辑下一条消息和点候选填入，当前请求完成前发送按钮继续禁用，避免同一会话并发；完成后保留草稿，失败也不覆盖已输入的新文字。
