# 企微多方案交付

仅修改企微适配器，不修改网站BOM内容、网页导出器或配单算法。网站BOM标题、列结构和参数由另一个任务统一实现；本轮仅在企微正文与附件文件名标明屏幕规格、方案和暂定状态。

默认只交付当前方案，其余方案保留序号选择。用户明确回复“全部方案”时，逐个调用核心已有方案切换，在确认返回selectedOptionId后分批发送。批量结束恢复原选中方案；失败则明确中断或恢复失败，不冒用其他方案数据。未能唯一确认方案身份时标“当前方案”，不猜方案编号。

28项适配器检查通过，含单方案选择、全部方案顺序、原选择恢复、私有资料边界和逐项失败。真实04版已确认一次配单四项全部发出（一图片三文件）。05版已部署，真实多方案批量发送尚未验收；测试不代表配单业务准确率或HDSet设备下发。
