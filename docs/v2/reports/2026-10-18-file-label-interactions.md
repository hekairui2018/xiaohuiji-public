# V2文件标签独立预览与下载（2026-10-18）

- 保留当前轻量文件标签布局，主体与最右侧下载为并列可交互元素，中间细分隔线。没有交互元素嵌套，各区域有独立hover/focus、title与aria-label。文件图标、名称、版本均在主体预览范围。
- PDF及已有支持格式复用`/v2/offline/preview`，下载复用`/v2/offline/file?…&download=1`；不新增预览器。非PDF外链未提供原文阅读入口或格式不支持时，主体显示明确提示，不直接下载/假装预览成功。固件标签也采用独立主体提示与原件下载。正文缓存不足时沿用现有阅读页的无正文提示。
- 文件原名、中英排列、型号/版本/历史及兼容条件处理不变。未修改后端分类、索引、原件、API或生产服务，仅两个本地前端工作区的app.js、product-resources.js、styles.css及合成回归。
