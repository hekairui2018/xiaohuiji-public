# 文件预览标题与中英两行排版

PDF原先直接访问/file接口，浏览器可能将接口名file显示为标签标题。现采用以原文件名为title的预览外层，iframe继续显示原PDF，独立下载和Range流保持不变。旧标签需重新打开新链接。

型号右侧按现有语言元数据/文件名线索分为中文行、其他语言行，中文在前，同一起点排列；保留每行已有日期顺序、名称、版本与链接，长名自然换行，不强求右端等宽。规格书和说明书采用同一展示函数。两个工作区分别更新，后端/前端独立仍保留。

按用户明确要求，操作指南从当前速查网页中隐藏，原件、索引及历史记录保留；此为展示选择，不宣称操作指南与使用说明必然内容相同。未改V1或G盘原件。

两套页面实际点击得到原文件名标题与原PDFiframe；中文/英文起点坐标一致。实际说明书接口操作指南当前展示0条。针对性预览、下载、目录和缓存检查通过。
