# 回车打断与候补发送

- 回车在回答中停止原请求，确认取消后沿用会话发送新消息；停止未确认则保留输入并恢复可操作状态，防止重复取消竞态。
- Ctrl+Enter 在处理过程中将消息放入输入框上方，当前回答结束后依次发送；等待时不新增聊天气泡。可移除候补，自动发送保留未发送草稿。
- 请求失败时暂停候补，可明确继续；停止后的旧流式事件不再更新当前回复。会话切换更新对应候补显示，OCR 后续查询复用发送生命周期，配单选项结束后也能继续候补。
- 修改 chat-controller.js、offline-client.js 的取消后事件保护、loading-status.css 的候补行、index.html 的提示与缓存版本；不改 API、模型策略或业务计算。
