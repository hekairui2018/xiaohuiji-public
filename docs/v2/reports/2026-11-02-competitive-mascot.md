# Product-aware mascot and explicit competitive knowledge

The mascot now offers short, source-backed competitive highlights after an exact product search. It shows at most two differences from the same comparison group. Shared features, missing cells, ambiguous values and conflicting records do not establish an advantage. A model without a supported difference produces no sales pitch.

An exact result remains visible when the catalogue also contains longer variants. Variant buttons run a new search only after the customer selects one. Approximate fallback results receive a model-check reminder. Starting another search clears the previous bubble; generic timed welcome messages were removed.

The explicitly selected workbook was extracted into a separate private knowledge artifact: one source, ten worksheets, 6,868 parameter cells, retaining brand, model, original value and cell coordinates. Startup verifies the original file checksum. Expert retrieval can query this source and read the returned evidence; the original workbook and extracted records are not published. Customer hints expose only the selected product's short highlight text.

Validation: 16 focused tests passed. Actual browser checks passed on desktop and a 390px viewport: exact-result preservation, optional variant selection, approximate-model warning, competitive highlights, close behavior and no horizontal overflow. The expert search/read tools returned an aligned two-model comparison without general retrieval. This is a tool verification, not a new model-answer accuracy benchmark.

Development release: `20261102-competitive-mascot-27`. It preserves every backend module from the concurrently delivered full-text cleanup release and adds the competitive knowledge module. The prior release remains available for recovery. The live page checks passed after activation; the approved firmware count remains 108 and the three sampled product parameter/document/firmware counts are unchanged.
