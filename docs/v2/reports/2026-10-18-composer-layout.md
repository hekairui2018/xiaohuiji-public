# 对话输入区布局整理

按用户要求将模式与连接状态放左侧，普通/访客放右侧同排，均位于输入行上方；删除空反馈占位的留白。移动端允许合理换行，无覆盖或横向溢出。

快速/专家采用与顶部导航相近的分段形式，选中项白色渐变、边缘高光、轻阴影微凸；悬停与按下反馈、键盘焦点可见。普通/访客选中项用既有蓝色区分。没有修改发送流程、模型接口或会话保存逻辑。

真实浏览器在1280、390、360宽度验证点击和Enter切换快速/专家、选中阴影差异、访客切换、桌面同排和所有宽度位于输入上方，无脚本错误或横向溢出。截图私有留存并目视检查；未重复运行模型生成。前端对照工作区先断言无并发变化，再只同步本轮局部；未重启后台、模型或一代。
