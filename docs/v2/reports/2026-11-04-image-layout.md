# 本地图片预览与OCR接入审查摘要

2026-11-04。

- 本地OCR适配器复用已安装灰Desk的独立PP-OCRv5 worker，仅管道处理传入图片，不启动剪贴板/远程连接。缺安装、异常、超时明确失败，不静默换OCR。协议测试用自造子进程，不公开灰Desk程序或模型。
- 新增图片布局预览组件：展示候选小格、空白和区域，用户明确确认图义及是否一箱一卡，之后仅填草稿；不自动发送模型或生成配单。跨会话隔离、长度限制保留。
- 本地7项针对性测试、实际Edge桌面/手机真实OCR和两张网格图的候选预览/确认通过。普通文字查询的模型响应受控，不能算专家质量评测；开发用图不算盲测。
- 本轮没有增加任意非矩形配单、带载校验或正式SSM能力。后续仍需统一几何任务状态及业务工具约束，不能用提示词冒充引擎支持。
- 公开交付为允许公开的适配器、协议测试、预览组件和精确接线patch。服务端几何处理、客户图片、OCR原文、运行配置和证据均未公开；这个审查增量不是可单独部署的整包。
- 接线要求现有本地OCR响应额外提供layout候选，status为candidate时含grid/cells/regions/warnings；region位置从0开始，cellCount是实占格数。候选没有业务含义或适用确认。原OCR text仍保持独立。
- 本地开发验收包image-layout-02，基于business-language-02增量，其他281个后端模块保留。没有发布一代或客服机。
