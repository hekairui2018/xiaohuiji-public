# V2 客服检索与诊断可靠性改进

日期：2026-10-23。本文只包含可公开的实现说明与脱敏验收摘要，不包含内部原件、数据库、客户记录、访问地址、私有配置或模型权重。

## 实际交付

本阶段代码已切换到 V2 运行服务，核心与资源索引均已重启。最终上线事务验收包含九轮真实快速问答和一轮真实本地模型回答；之后再次核验网页、浏览器对话、公网咨询、授权下载和内部接口隔离。守护进程恢复正常保活，一代服务未参与切换。

第一次切换后，真实专家复验返回失败，已恢复原源码和启动配置。该失败保留，没有将 HTTP 成功或局部测试通过当作质量达标。修正诊断契约后进行了第二次切换，最终真实专家验收 HTTP 200、一次模型调用、约 12.9 秒。回滚及两次切换的完整回执保留在本地私有交付记录中。

源码与本文同步到既有 [公开审查仓库](https://github.com/hekairui2018/xiaohuiji-public) 的 main。数据库、原文、运行配置和原始对话不在同步范围；具体提交以本报告所在 Git 历史及交付回执为准。

## 检索与上下文

- 快速模式保留原话、常见同音错字解释及任务字段来源；不模糊修改型号后缀、芯片、版本、尺寸、单位、文件名或引用内容。分辨率补充、参数后的规格书追问、纠正信息与模式切换沿用已有任务。
- 参数检索优先规格字段与参数原文，区分板卡尺寸、像素分辨率、带载、网口及灰度。拒绝以故障措施、修订日期或章节编号代替参数；断裂数字不任意拼接。型号、版本和条件分别保留。
- 操作检索保留具体任务与通信方式，读取连续章节及后续注意事项。界面步骤只在插图中出现时明确说明文字证据不足，不补造菜单。
- 复杂问题可推荐专家继续，快速查询不自动调用模型。长输入、同一会话交接、失败恢复草稿、新咨询取消旧响应和窄屏显示已接通。

这些单元由确定性规则生成，**未经逐条人工审核**。读过片段、读完分页、章节边界完整与语义适用性是不同条件；不将自动案例标记为已核实现场方案。未读候选正文在回答阶段隐藏，旧案例记录不与已启用的角色案例混合引用。

## 专家回答契约

产品事实需有可核验引用；一般分析与公司事实分开。未读完的片段、未核实适用条件的案例阈值，以及其他候选的措施不能直接成为现场方案。来源和数字校验只能发现部分问题，不能证明自由文字的全部语义正确。

诊断状态跨短技术追问和快速/专家模式保留，只记录客户观察；独立产品问题不继承旧故障。区分肯定陈述与假设拓扑、软件发现或发送失败与屏体显示异常、重插与已完成的部件替换对照。

对“已确认拓扑的屏体显示故障，下一步先查什么”使用受控动作：模型选择尚未完成的排线、模组对照，或选择只记录核对标签；具体步骤由系统模板生成，包含断电、兼容规格、已知正常备件、单变量及结果不能确诊的限制。已做过的部件对照从可选项排除，澄清也通过类别及模板生成，不能借问题字段插入调参或换卡指令。这不是自动确诊，也不替代具体设备操作说明。

开发题、参与修改的题和既有失败表达均属于回归，**不是客户盲测**，不据此计算整体客户准确率。依赖内部知识数据的测试未通过复制私有数据来公开复现。另有一项历史路由断言在未改基线上同样失败，未更改期望值以冒充通过，也未计入上述定向通过数。

真实模型验证保留成功与失败：此前参数回答约 63 秒、拓扑澄清约 28 秒，另有约 98 秒的回答因跨案例措施及适用性问题被人工否决；第一次上线真实专家返回 503 并执行回滚。改为受控下一步动作后，两次预览复验分别约 15.9 和 15.4 秒，最终上线复验约 12.9 秒；这些都是同类开发问题的测量，不能推广为所有专家问题的速度。

公网内容阅读仍限制在已核验白名单交集：当前内容提供器可读取 25 份核验原件，登记对象白名单为 222 项，两者口径不同；新增内部角色索引没有因此获得公网公开权限。签名链接在返回时重新签发，失败及取消不占用新咨询容量。

仍未完成独立客户盲测、全部资料人工审核、全部图示操作识别及所有开放式专家任务的稳定性验证。此次没有宣称全量配单、连接图与配置文件映射均已完成。原文缺失、图示信息不足及未经验证的现场诊断继续明确保留边界。
