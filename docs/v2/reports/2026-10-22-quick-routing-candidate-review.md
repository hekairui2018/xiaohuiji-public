Status: experimental source checkpoint; local information system awaiting final acceptance. This sync is not a deployment or a claim of completed public AI service.

## Validation and limits

- 210 targeted routing, retrieval, ordering, expert-isolation, session and access checks passed against the exported code with controlled local data; 7 dependency/access checks also passed. Syntax checked for all 25 exported code/test files.
- The public repository deliberately excludes internal datasets and carries empty data manifests. An initial direct run failed at these data checks. The controlled-data rerun used local data-loader bindings, with no assertion weakening or fabricated model answers. Test harness and private fixtures are not published. Data-dependent tests cannot be reproduced from the public checkout alone.
- Three random batches of 100 de-identified customer questions were evaluated locally. Third-batch single-intent diagnostic: baseline 43/96; candidate first attempt 60/96; development retakes 80/96 and 85/96; four ambiguous/multiple-goal questions were not forced into one label. Retakes are regression results, not blind generalization scores.
- Human review of that 100-answer checkpoint: 30 inadequate, 44 partial, 26 useful resources/evidence/clarifications after one evidence-based grading correction. Useful clarification is not a solved customer problem. A later 16-question development retest had 11 useful, 3 partial, 2 inadequate answers. This is not final acceptance.
- Quick HTTP evaluations made zero model calls. Real model-assisted comparison has not been performed.

## Confirmed unresolved causes

Some supported evidence is rejected by literal query-residue matching; operation terms can retain background narrative rather than the requested task; failure templates can ask irrelevant hardware questions; case ranking can lose USB/offline trigger conditions and show duplicate incidents; multiple products and actions are not always bound separately; candidate lists can be truncated before relevance ranking. An official product specification was available for one previously reported evidence gap: the gap report was wrong, and the private reference answer has been corrected with original-page evidence. Diagnosis is not a claim that these defects are all fixed.

Only code, synthetic/de-identified short regression examples and this aggregate report are published. Original question workbook, private question bank, historical answers, customer cases, source excerpts, databases, credentials, model files and internal locations remain excluded. Production services and the original working tree were not updated or restarted.
