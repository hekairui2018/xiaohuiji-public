# 特殊配单分支接通与当前交付边界

本轮已在开发站加载并经真实网页验收。范围为专家/快速问答共享的配单路径；未修改一代和客服机。LCD不在本轮范围。整体问答80%正确率尚未验收。

## 触发条件与输出

共同条件：模组点间距、像素、扫描、接口、颜色、使用环境；屏体给模组排列、实际尺寸或像素均可。严格配单还需同步/异步、接收卡/直控架构。库记录与数学推导单独留痕，不冒充客户已确认。

| 分支 | 触发和额外条件 | 当前可交付 | 尚未完成 |
|---|---|---|---|
| 常规矩形 | 同步接收卡，或异步接收卡；未指定类别时按模式和架构选有源类别 | BOM、网口图、标准SSM | 现场芯片/固件兼容及实机下发不由几何测试确认 |
| 直控 | 明确直控，来源支持的异步卡和HUB带载范围 | 主控/模组BOM、逻辑接口区域 | 对应控制软件屏参；接收卡SSM不适用 |
| 普通箱体 | 每箱横竖模组数＋整屏横竖箱数，遵守一/两卡分箱规则 | 本地可核验分箱可出标准图/SSM；其他路径展示官网选型原生图 | 官网复杂分箱结果到标准配置的映射 |
| 折宽/打折 | 所选设备支持discount且屏宽达到设备记录的minWidth，同时满足画布/端口容量 | 保留经过物理覆盖校验的BOM和连接预览 | 折叠后逻辑坐标及配置格式 |
| 拼接器 | 明确拼接器；输入源2K或4K帧率；输出板类型 | 官网选型、接收卡数、连接图和输出图 | 输出组与标准配置文件映射 |
| T16链路 | 明确T16及前端类别；拼接器前端需源规格及HDMI/DVI输出板；不能用网口输出板冒充视频输出 | 官网实际T16数量、前端型号、接收卡数、连接图 | 各T16设备的独立配置及实机验证 |

| 播放盒级联 | 明确级联数量≥2，型号有来源的级联能力与容量 | 符合功能要求的官网选型与图 | 多设备协议、分屏及配置映射 |
| 多块独立屏/异形 | 不可并成单矩形屏 | 澄清独立工程条件 | 通用多屏/异形求解未交付 |

## 本轮修复

- 新增有来源的场景字段契约，缺输入源/输出板/前端条件时直接问缺项，不重复计算多个假设。
- T16是链路组件，C16共享是功能标签，不再错误加入第二台主控列表；直接解析和任务上下文使用同一角色处理。
- 箱体阵列能推导整屏模组数，保留独立推导记录；已生成的官网结果及原生图不再在对话封装中丢失。
- 官网绘图异步结束后调用原格式化函数刷新结果，避免初始T16数量0和最终图不一致。T16数量不足1或型号缺失不能判成功。
- 官网类别回退仍可能忽略级联能力；先用有来源的设备条件筛选，再指定该设备执行官网绘图。客户指定设备、功能、架构冲突不静默丢弃。
- 原生图支持原尺寸展开和图片下载。T16展示不再列不适用的T902零值；原始官网结果仍保留在计算结果包。
