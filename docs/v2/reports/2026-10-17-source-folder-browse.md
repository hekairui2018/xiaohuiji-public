# 三类速查资料按来源目录归类

范围仅规格书、说明书、操作视频。沿用现有资源索引和缓存，不移动、改名、删除或复制原件，不重扫正文、不OCR、不调用模型。软件/固件原功能保留，未扩大整理范围。

| 来源目录名称 | 网站类别/分组 |
|---|---|
| 产品规格书（LED）、产品规格书（LCD） | 规格书；按现有产品子目录 |
| K系列-接收卡、R系列-接收卡 | 合并接收卡 |
| A系列-播放盒、H系列-多媒体播放盒 | 合并播放盒 |
| B、C、D、T、VP、MS及分布式中控、信号传输、配件 | 保留各自来源分类含义 |
| 操作说明/文档、系统操作手册、烧录操作说明 | 说明书；按原有全彩、单双色、LCD、配件等分类 |
| 云平台、APP、屏掌控 | 合并云平台、APP |
| 操作视频、烧录视频等 | 操作视频；目录优先、直接列文件 |

分类最多一个可展开分组，组下直接文件；目录路径仅用于定位。目录与明确正文/文件格式冲突进入待确认，不按文件名改归属。无法确定原分类的记录合并为一个分类待确认组，不继续产生推测分类。型号/版本与目录分类分别保存，不从目录猜型号或兼容性；已确认版本关系、未知版本保留原依据。

接口：`/api/docs?cat=spec|manual&view=flat` 的 `docs.groups[].items[]` 直接列去重文件，没有products子层；默认旧响应兼容，并增加docs.flatGroups。每份文件保留associatedModels，跨型号共享原件按内容身份去重，不合并相近文件名。`/api/videos`本地只列操作视频候选；明确宣传、培训或用途不明确的条目仍保留在原始索引。前端资源未修改，前端窗口直接按新契约消费平铺字段。

实测：规格415份去重可用原件、说明400份；操作视频303条可用列表，另101条宣传/培训/用途不明确的候选未纳入操作列表。这是分类筛选结果，不是新增下载量或全部视频内容已人工看过的结论。旧规格/说明可定位文件ID在各保留类别内均能追踪，没有原件记录丢失；旧13条未定位当前引用等仍保留错误状态。

56项针对性Node检查通过，包括来源目录冲突、K/R与A/H合并、一层平铺、去重、未知版本保留及新增目录行继承。实际4个规格/说明原件下载SHA一致，预览200、视频Range206、软件业务字段前后相同、8620仍独立可用。没有通过重跑历史模型试题证明本阶段。

同时修复正常浏览器顶层导航被Sec-Fetch-Site跨站标记误拦的问题：已授权来源/Host下wiki导航200，跨站API仍403，Origin、来源地址、iframe和写请求限制保留。仅重启本地8520及只读索引，未再次重启8620或触碰一代。

旧分类测试有两处预期按用户新规则调整：证书目录中仅文件名写规格书仍按目录；目录与已解析正文规格书明确冲突时待确认。没有调整模型测试答案或宣布全部资料已人工确认。
