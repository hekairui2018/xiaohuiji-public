# Wiki 标注复用与文件结果交付

文件查询沿用 Wiki 已批准目录的文件身份，复用品牌版/中性版、语言、版本、大小和已有说明；不按同名文件推定版别，不让模型重新识别这些字段。文件名本身已有版本时不重复堆标签。重要版本冲突保留简短提示，其他说明展开看。

普通资料按钮桌面两列、每个高50px，文件名、预览和下载保持；窄屏为保证可读性转单列。固件样式与系列解释沿用另一窗口，本轮未改它们的样式或识别规则。普通会话刷新后保留新查询的版别、文件链接和说明。

纯文件请求需要本轮工具结果，不允许直接复述历史文字代替交付。`quick`、`search kind=resources`及`search kind=files`共用文件登记结果；明确且符合原有交付检查的结果直接交付，候选需模型选择时用`deliver`选择真实文件卡片。参数分析、对比等复合请求保留分析动作，不强制变成纯文件交付。未增加按文件标注重新分析的模型调用或新检索库。
