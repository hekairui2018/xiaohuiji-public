# 快速模式资料接入与职责整理

本轮只整理快速问答。Wiki、全文检索的查询规则和原索引不在本轮修改范围；经验案例、复杂分析与配单保留专家职责。

## 查询与来源

| 客户需求 | 查询方式 | 交付内容 |
|---|---|---|
| 索要规格书、说明书、视频、软件、固件、配置 | 复用既有文件登记 SQL；保留型号、版本和文件身份 | 原文件预览、下载；相近候选明确标识 |
| 参数、功能、条件支持关系 | 产品速查表优先，再补充技术表 SQL，最后既有规格书分节 | 原单元格值及备注，或相关正文和原文件 |
| 两款产品比较 | 从产品速查表抽取对应两列 | 两列完整值、差异与来源 |
| 简单操作 | 设备与任务关联软件，检索软件/设备手册分节及相关视频 | 原文操作、适用条件、原文件；步骤不足标部分 |
| 标准常见问题 | 七份 FAQ 的问题、关键词、条件、答案字段 SQL | 完整答案及条件；不把历史案例当当前结论 |
| 芯片、译码选择 | 复用已有芯片关系 | 原关系及软件选择；不推断实体替换或固件适用性 |

产品速查表复用已解析的 6868 个单元格。补充技术资料共 12127 条，其中 9957 条有记录、2170 条未注明；七份 FAQ 共 831 条，其中 795 条完整、36 条缺答案等内容；空点位置表 39 条。未注明不解释为不支持，不完整 FAQ 不生成标准答案。

接收卡固件支持表的三个空白子表、只有标题的产品目录均记录为来源缺口，不制造内容。LCD 技术表保留参数资料，客户、生产及业务登记表不作为技术问答内容。竞品原表未接入快速问答。

软件说明书由另一开发任务增量登记；本轮直接引用其 SQL、分节与向量，不重新解析原件。电脑调屏、手机操作、节目发布分开选资料。同一设备可关联多个软件；手机参考教程不等于声明全部设备兼容。

## 代码职责

- `section-answers.cjs`：快速模式任务路由与来源优先级。
- `quick-answer-format.cjs`：单元格、FAQ、条件字段的展示。
- `quick-operation-context.cjs`：设备与任务的软件关联、操作资料范围和连续小节选择。
- `file_registry.py`：只读复用授权文件登记，不读取正文或加载向量。
- `quick_knowledge.py`：结构化技术表与 FAQ 的 SQL 检索、适用条件核对。
- `quick_sections.py`：软件说明书专用的内存检索视图，复用既有章节及其向量；不写索引、不修改全文实例。
- 两个构建工具仅用于新增结构化来源；已经有的登记与解析产物直接使用。

本轮删除不再从当前启动入口可达的 14 个旧 RAG、预读、CSV 预览与模型试验模块，以及对应专用试验工具和测试。仍被公开查询或专家工具依赖的模块保留。文件下载授权、芯片映射和配单计算没有以“旧代码”为由删除。

## 验证口径

100 条固定回归按来源设计，覆盖参数、比较、补充表、FAQ、文件、芯片、边界和操作。自动检查原值、来源、文件身份及分流；操作项自动通过仅表示找到相关资料，仍须人工审阅，不能宣称 100% 回答正确率或盲测准确率。

开发站当前版本为 `20261103-quick-knowledge-24`，基于另一开发任务的软件登记版本增量构建，保留其前端与登记功能。已完成真实页面查询与四类原件 SHA 核验；六组 Wiki/全文查询及三个既有数据文件对照不变。原软件登记版本保留回退。

61 项相关 Node 检查与 6 项 Python 检查通过。候选入口和真实 8520 的固定 100 条回归均符合自动检查条件；其中五条操作题的人工复核结果为两条有对应 Wi-Fi 设置正文，三条仅部分操作说明或相关视频。手机发送节目另外核对了屏掌控全彩手册原文与适用性提示。六轮真实页面交互无脚本异常。

旧的全仓测试存在失败，未以本轮定向通过代替全仓通过。完整失败日志、来源定位、各次回归、回退配置保存在本机私有验收目录，不公开原件、题面、数据库、向量或运行配置。

公开副本提供通用模块、Python合成检查、接线补丁和Node审查测试文本。Node测试依赖完整项目的既有业务解析器，未扩大公开私有配单实现；本次公开副本实际运行Python六项通过，61项Node结果来自完整开发工作区。
