# 2026-11-04 消息操作栏

- 客户消息：复制、编辑。编辑把原话放入输入框，由客户修改后发送，保留原消息；不会自动发送或改写历史。
- 小灰机回答：复制、有帮助、没帮助、朗读、更多。反馈为当前页面内的本机标记，不上传；更多包含重新提问（放回输入框）和保存回答文本。
- 桌面操作与发送时间在消息悬停或键盘聚焦时显示；触摸设备始终显示。时间复用已有消息时间，刷新恢复后保留。等待气泡不添加操作。
- 独立 JS/CSS 模块，无后端、模型或检索改动；开发站增量更新前保留旧入口页面，可撤回两项资源引用。

验证：实际开发网页入口配合合成回答，在桌面和手机触摸模式各验证复制、编辑不发送、赞踩互斥、语音调用/停止、更多菜单/Escape、文本下载、刷新恢复、可见性和横向不溢出，均通过。语法检查通过，无页面脚本异常。

语音调用由浏览器桩验证；扬声器实际发声没测，因为本轮使用无头浏览器。未调用模型，本轮不计入模型答案质量或性能测试。
