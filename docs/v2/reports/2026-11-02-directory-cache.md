# 配置目录缓存与折叠滚动稳定

目录在服务端短时复用构建结果，合并并发构建；前端按目录、分页、查询和排序缓存独立响应，合并在途请求，调用方拿到独立副本。根目录版本变化时清理旧页面，失败请求可重试。

前端每批最多两页预读目录元数据，预算和缓存容量有限制；文件正文不预下载，原件下载保留实时校验。点击展开或收起时保存滚动位置，底部收起保留必要空间，避免浏览器因页面缩短而强制向上跳动。

验证：15项相关检查通过。真实浏览器返回配置页没有重复根请求，滚动236px收起后仍为236px；配置下载SHA256验证通过。本机暖目录请求4–16ms，改前645–726ms。缓存到期首次加载仍可能较慢；这些数字不代表其他设备或网络的性能保证。

保留上一发布版本可回退；未修改资料原件、资料清单、RAGFlow或模型。
