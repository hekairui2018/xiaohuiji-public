# 生成中发送新消息并重解上下文

按用户要求，文本生成期间输入框和发送按钮保持可用。发送新补充/纠正时，取消当前浏览器请求并请求后端中断同一会话的模型任务；等待该任务退出后发出新消息，模型使用保留的客户历史重新理解。前端以请求代次丢弃迟到结果，旧请求不能清除新请求的等待状态或覆盖新结果。

取消中的助手失败/半截答复不记入模型会话；客户原话保留。若前一条还在前端连接检查、尚未进入后端，停止请求会保留该客户原话，避免新消息的“上面”失去对象。不自动关闭会话或清空资料、历史。后端独立中断接口只在既有内部访问边界开放，等待旧任务退出有超时，不并行抢写同一会话。

90项相关测试全通过，单项增加验证中断排空、保留客户消息、取消结果不污染历史及尚未入站的连接准备竞态。真实网页两场景通过：发送后立即改问；以及模型已有实时计数后改问。两者均由6363闪屏案例转为R712规格书，最终只交付R712资料、历史保留两条客户消息、未出现被取消的助手答复。前端第一版实测发现请求代次变量漏定义，已修复并重测，失败原始记录保留。
