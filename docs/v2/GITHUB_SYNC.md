# 二代GitHub同步边界

从2026-10-16起，二代阶段交付默认包含公开源码和可公开报告同步，用户明确“不push”时除外。

- 目标：`https://github.com/hekairui2018/xiaohuiji-public` 的 `main`。这是审查总仓库，二代使用 `v2/`、`docs/v2/`；既有一代历史保留。
- 必须核对remote、分支、远端提交、目录、diff、敏感内容、必要回归及远端提交实际存在。
- GitHub同步不等于部署。没有明确部署要求，不启动生产部署、不重启一代、不修改现网。
- 只公开源码、许可公开的测试脚本、合成/脱敏数据、报告摘要及指标。内部原件、客户资料、原文证据、数据库、模型权重、凭证、内网位置和未批准ZIP不公开。
- 资料不足以确认正确remote时停止，不猜测、不force push、不覆盖历史或删除失败报告。
- 已参与修改的题目只能作为回归，不能继续冒充新盲测。公开统计标明抽样方式及不可测项。
