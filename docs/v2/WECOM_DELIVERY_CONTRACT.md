# 二代企微结果适配契约

企微桥只转换既有问答服务的输出，不重新判断意图、计算配单或润色答案。`presentation.cjs` 生成有类型的交付清单，`responder.cjs` 逐项发送并保存回执。

| 核心返回 | 企微交付 | 约束 |
|---|---|---|
| `reply`、可见文本流与处理状态 | 流式文字，长文分段 | 不发送提示词、思考、原始通信日志 |
| `result.bom/previewBom` | 物料文字、CSV、沿用网页导出器的Excel | 暂定标记、原数量与假设保持 |
| `result.hdsetSvg/topologySvg/configurationSvg` | PNG图片 | 仅渲染返回图，不重绘业务布局；拒绝外部资源 |
| `result.nativeOrdering.diagrams` | 企微图片 | 保留原生图；不据图生成配置 |
| 允许导出的既有配单结果 | SSM、接线ZIP、原生BOM附件 | 调用网页同一导出接口；接口拒绝就记录失败，不放宽校验 |
| `result.options` | 编号方案，回复序号继续 | 发送网页相同的“配单方案：ID”；按会话隔离，15分钟有效 |
| `parameterComparison` | 参数对比文字和CSV | 未记载、冲突等原值保持 |
| `caseCards` | 现场、关系、差异、原文结果和内部入口 | 内部案例原件及图片保留原权限，不自动转传到企微云端 |
| `results/fileGroups`、软件、视频、固件附件 | 已批准原件的文件、图片或视频；否则提供现有可用入口 | 名称与SHA256匹配批准清单；真实路径、大小、内容再校验，最大20MiB |
| 型号候选、`followUp/wecomOptions` | 回复数字的候选项 | 只使用核心返回值，不推断兼容 |
| 超限、未登记或未知附件 | 明确说明及已有网页入口 | 不静默丢弃，不凭文件名越权找原件 |

文字发送、附件上传及媒体下发分别确认。交付回执区分完整、部分失败和明确入口说明；单项失败继续后续项。回复“重发附件”可重发当前会话最近结果，无需再调用模型。重启后内存中的选项和最近结果清空，核心原会话继续保留。

真实回调、核心结果及逐项回执只保存在私有运行目录。公开源码和报告使用合成样例，不包含客户需求、原答、原件、内部路径或凭据。网页需要人工填写的复杂工程设置仍在网页操作，企微不代填未知配置。
