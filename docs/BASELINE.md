## 3. 当前启动方式

建议 Node.js 22；本次实际回归环境为 Windows PowerShell、Node.js **v24.19.0**，执行文件 `E:\开发工具\Node\node.exe`。以下是本地手动启动说明，本次未执行服务启动。

### 核心服务

在项目根目录执行：

```powershell
$env:PORT = '3789'
$env:HOST = '127.0.0.1'
node backend/server.js
```

- 快查站：`http://127.0.0.1:3789/quick`
- 问答：`http://127.0.0.1:3789/huiai`
- 健康：`http://127.0.0.1:3789/api/health`
- 代码默认端口是 3788，必须显式指定项目端口 3789。

### 企业微信桥

配置 `wecom-bridge/.env` 中的机器人凭证；另开终端，从项目根目录执行：

```powershell
Set-Location wecom-bridge
npm install
npm start
```

入口 `src/index.mjs`；健康接口 `http://127.0.0.1:3790/health`，仅监听本机。拓扑图片使用本机 Edge/Chrome，渲染不可用时回退文字。

### 质检后台

另开终端，在项目根目录执行：

```powershell
$env:ADMIN_PORT = '3791'
$env:ADMIN_HOST = '127.0.0.1'
node admin/admin-server.cjs
```

访问 `http://127.0.0.1:3791/`，健康接口 `/api/health`。后台默认可监听所有网卡，上述命令限制在本机。

### 现有部署与配置

交接资料记载客服机部署在 `D:\xiaohuiji`，由 `scripts/watchdog.ps1`、`scripts/watchdog-3791.ps1`、`wecom-bridge/scripts/ensure-bridge.ps1` 等保活/重启工具管理三个服务。这些脚本含现网路径约定，不能直接当作开发副本启动方式。

主要配置：核心 `backend/.env`，企微 `wecom-bridge/.env`，OSS 工具 `scripts/.oss-config.json`（已有占位示例）。模型、OCR、企微和飞书能力依赖各自外部配置；飞书及日志鉴权显式读取后端 `.env`。真实凭证不写入本文。资料下载还依赖对应云端资源或本地资料，克隆源码不包含全部现网运行条件。

## 4. 当前已有功能

1. **售前快查**：产品参数/规格书、芯片固件尾缀与下载资料、软件和操作视频。
2. **售后检索**：显示、启动供电、网络、节目内容、固件五域的案例匹配，返回处理方法与来源。
3. **屏体配单**：自然语言和结构化输入、参数追问、设备选型、接收卡数量、带载与网口分配、BOM、SVG 拓扑。
4. **SSM 输出**：标准矩形配单的 HDSet 连屏文件生成与网页下载；离线测试覆盖 1/2/4/6/8/10/12/16/20/24/30/40 口。
5. **意图与边界**：售前、售后、配单、软件及未知意图；友商、标书、非 LED 场景边界；异形/多屏等场景引导或转人工。
6. **网页与企微共用答案**：网页富展示，企微文本/图片与回复序号，会话历史及选项还原。
7. **问答质检**：记录查看、备注、意图正确/错误/转人工标注。
8. **日志接收及飞书**：升级助手日志鉴权接收、本地留底、附件同步、动态读取主列、字段失效有限重试、保留人工列。

飞书故障恢复及历史日志补齐已在 2026-10-12 发布验收中记录，不作为本基线新功能或当前未修复故障。
