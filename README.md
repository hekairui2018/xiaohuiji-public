# 小灰机（xiaohuiji）

LED工程辅助系统的完整第一方源码审查仓库，包含一代实现与独立二代。当前公开快照对应源提交 bf923af901dbc88f91895a3ae914f513a1d05430，更新日期2026-10-14。

## 项目结构

- backend：一代HTTP入口、产品查询、售后、配单、SSM和飞书日志同步。
- frontend：产品速查与智能对话页面，地址分别为 /quick、/huiai。
- admin：问答质检后台源码。
- wecom-bridge：企业微信桥接源码及依赖声明。
- v2：二代独立路由、产品证据消费、诊断状态流程、确定性选型计算、BOM/拓扑/SSM及可选模型适配。
- scripts：数据构建、回归及运行工具。
- data、v2/data、backend/ordering/data：业务数据的空结构模板。
- docs、reference：公开说明与内部/第三方资料占位。

## 运行与依赖

Node.js 22，核心采用原生HTTP与文件系统；前端为原生HTML/CSS/JS。企微桥依赖见wecom-bridge/package.json。

二代模型不是工程决策核心：没有模型仍可使用确定性解析、规则和计算；本地Qwen适配尚不代表已完成在线联调。

本仓库仅公开代码。真实产品参数、固件、案例、原始规格书、客服日志、部署信息、凭证与第三方官网源码不公开；占位不会替代真实数据。需提供自己的授权数据与配置后才能运行数据相关功能/回归。不能把此公开副本视为可直接生产部署的安装包。

数据恢复后，二代入口为node v2/adapters/http/server.cjs 4389；测试入口node --test v2/tests/*.test.cjs。独立试运行工具见v2/tools/start-trial.cjs，其配置必须明确指定本机独立端口和知识版本。

旧实现保留供代码审查；/quick不调用对话意图路由，/huiai通过共享知识服务处理咨询、配单、售后。源码更新没有修改或重启现网。
