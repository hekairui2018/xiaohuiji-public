# Private evaluation inputs are not distributed

This public snapshot contains implementation and permissible tests, not company source documents, customer questions, expected engineering answers, internal databases or review ZIPs.

Some evaluation-preparation and manually annotated helpers contain private records and are therefore not distributed. This does not remove functionality from the internal development project. Data-dependent historical tests require separately authorized data; their internal results are reported as historical measurements, not reproducible public test passes.

The optional complete-evidence experiment accepts authorized external fixtures. Its private `prepare()` dataset generator is withheld. Resource indexing requires an explicit authorized resource directory; it does not scan an internal drive by default in this export.

Portable export changes affect source/configuration defaults and synthetic fixtures only. No private Git history or deployment automation is imported.
