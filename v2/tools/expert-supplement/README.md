# 专家模式知识补充

此目录仅包含处理代码。培训课件、图片、OCR、索引 JSON、客户案例及访问凭据保存在私有目录，不提交 Git 或发布到公网。

构建器、逐页提取清单和 OCR 结果留在开发机私有环境。候选索引保留文件、页码、原文、图片识别来源和 `unreviewed-training-source` 状态；安装包不参与构建。图片识别只是线索，精确数字要核对原图。运行时由私有配置指向索引文件。

专家的 `search_evidence` 对案例、FAQ、产品、原文及需要复核的资源查询，并行获取既有公司证据与知识补充。公司资料完整可直接交付时保留原路径。补充材料不能单独确认型号参数、固件兼容或其他版本的现场操作；模型回答应带来源页码，并按现有安全和引用规则校验。快速模式、文件直达和配单计算器不读取此索引。

公开审查仅包含通用检索模块与脱敏结果；具体资料、构建器配置、完整运行集成及其测试在本地源码提交中。上线前应在独立端口实际重放包含公司案例和培训资料的两类问题，并检查工具记录里的补充证据 ID。
