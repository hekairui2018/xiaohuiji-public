# 新代码格式检查

开发工具独立于运行依赖。安装固定版本的 `package.json` 依赖后执行：

```powershell
node v2/tools/quality/check.cjs
```

默认检查 Git 工作区内修改及新增的 JavaScript 文件，也可在命令后明确传文件列表。规则为单行不超过160字符、函数内不新增 require、直接嵌套三元不超过两层。AST解析避免把注释、字符串里的问号算作三元运算。

`baseline.json` 只记录规则启用前 HEAD 的存量，按文件、规则、代码指纹和次数豁免；不是按文件整体豁免。新违例不能通过重新生成基线消除。首次建立基线的参数是 `--record-head-baseline`，已有基线会拒绝覆盖。

格式化采用Prettier 3.6.2；Python采用Black 25.1.0。运行程序不加载这些工具。原文字符串和正则中的长行应拆成命名常量或有说明的独立处理，不靠关闭检查掩盖。全文/Wiki业务行为不由格式工具改变。
