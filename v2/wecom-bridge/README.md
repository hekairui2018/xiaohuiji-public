# 二代企微接入

复用现有机器人和二代本机问答接口。每次查询检查专家开关；关闭、保护或模型错误时回快速模式。会话按人隔离；群聊按群及提问人隔离，同会话串行，消息ID去重。图片通过现有OCR接口处理。回复使用企业微信官方SDK回调帧，不主动发测试消息。

私有JSON配置包含 `botId`、`secret`、`sdkRoot`、`baseUrl`、`port`，不得提交。`sdkRoot` 指向安装了 `@wecom/aibot-node-sdk@1.0.7` 的独立私有目录；`baseUrl` 必须是二代回环地址。启动：`node main.cjs <私有配置绝对路径>`。健康端口仅监听回环。

运行不改变网页专家开关或保护策略。文件只列名称，不把内部文件句柄转换成公网链接。快速模式沿用240字限制，长问题明确请客户缩短。此通道不提供网页的布局确认与配置包交互。停止接入进程即可回退；不要自动恢复已被用户停用的一代。

验证：`node --test core.test.cjs`。真实企微收发需收到一条来自客户的消息后确认，认证成功不等于收发验收。
