# 二代企微接入

复用现有机器人和二代本机问答接口。每次查询检查专家开关；关闭、保护或模型错误时回快速模式。会话按人隔离；群聊按群及提问人隔离，同会话串行，消息ID去重。图片通过现有OCR接口处理。回复使用企业微信官方SDK回调帧，不主动发测试消息。

私有JSON配置包含 `botId`、`secret`、`sdkRoot`、`baseUrl`、`port`，不得提交。`sdkRoot` 指向安装了 `@wecom/aibot-node-sdk@1.0.7` 的独立私有目录；`baseUrl` 必须是二代回环地址。启动：`node main.cjs <私有配置绝对路径>`。健康端口仅监听回环。

运行不改变网页专家开关或保护策略。可选 `documents: {manifestFile,rootDirectory}` 指定已批准公网资料的登记清单和根目录。文件按名称与SHA256精确匹配，发送前再核验根目录、大小与实际SHA256；同名不同内容保留，回复标出版别与语言，原文件通过企微原生附件发送。未登记的内部原件、路径及下载句柄不对外转换。未配置时关闭附件交付。

快速模式沿用240字限制，长问题明确请客户缩短。此通道不提供网页的布局确认与配置包交互。停止接入进程即可回退；不要自动恢复已被用户停用的一代。

等待提示失败不会中止问答；最终回调失败尝试主动文本回复。仅对明确连接拒绝的请求短暂重试，已可能入站的请求不盲目重放。健康信息包含失败阶段与通用错误码，私有运行日志记录脱敏异常。

验证：`node --test core.test.cjs documents.test.cjs responder.test.cjs`。真实企微收发需收到一条来自客户的消息后确认，认证成功不等于收发验收。
