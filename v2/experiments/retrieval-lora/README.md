# 小灰机 V2：第一步检索 LoRA 实验

这是独立本地实验，不修改小灰机正式模型、配置或运行服务。模型仅学习输出 `search` / `clarify` JSON，已有 V2 负责执行检索、授权阅读和来源校验。

## 目录与运行

- 脚本：本目录。
- 隔离 Python、原始权重缓存、适配器和原始日志：`tmp/retrieval-lora-20261020`。
- 快速审核表：`tmp/retrieval-lora-20261020/data/review.html`，可按型号、状态或编号筛选。
- 数据：100 条候选，其中 80 条明确意图通过本地工具/政策审核（不是人工签字），20 条真实案例现象的首查动作待工程师确认。
- 本轮训练48、验证16、独立测试16；待审核20条全部排除。真实案例只读取现象和型号元数据，没有把处理结果当训练答案。

PowerShell 执行 `./v2/experiments/retrieval-lora/run.ps1 -Install` 可依次检查/安装、获取权重、检查数据、跑基线和训练、验证独立接口与现有只读工具。安装和运行均不操作其他服务。

`worker.py` 是带状态日志的后台顺序执行器，支持分段下载恢复；状态位于 `worker-status.json`。不重复并行启动同一实验，不自动增加训练轮数。

## 固定实验条件

- 官方 `Qwen/Qwen3-0.6B` safetensors，revision `c1899de289a04d12100db370d81485cdf75e47ca`；下载检查官方 LFS SHA256，禁止用 GGUF 训练。
- 原始非量化权重 + Unsloth LoRA；BF16，rank 8、alpha 16、batch 1、梯度累积4、序列512、36个优化步骤、学习率2e-4、固定seed3407。
- 首步完成保存最小训练回执；只保存最终 LoRA 适配器和 tokenizer，不合并、不导出 GGUF，不保存整模型训练检查点。
- 同一个提示词、同一个测试集、同样的贪心生成、Thinking关闭，原版先测、再训练、再测LoRA；没有强制JSON语法、修复输出或把测试答案塞入提示词。
- 目标约100输出Token，保留256个生成Token安全上限；实际Token数量和截断单独记录。
- 开始时空闲显存不足6500MiB则停止实验并报告，不关闭其他模型服务。

## 如何解释结果

分别记录JSON语法合法率、协议合法率、首步动作、资料类型、型号、芯片、版本、关键词覆盖及字段全部匹配率。型号后缀不能混用；另报告只在有型号/芯片/版本的适用样本上计算的指标，避免大量空字段抬高分数。

平均耗时与tokens/s采用同样的非计分warmup、单条CUDA同步计时，保留每条原始输出。原始用量不经过答案修复。词覆盖是固定词组评分，不是独立工程师的语义正确性判定。

测试集只有16条合成明确意图，不能把它解释成真实售后工程判断正确率，更不能把“查到历史案例”当成原因确认。工程判断候选仍需工程师审阅，当前实验不据此宣称掌握公司全部经验。

独立接口仅绑定127.0.0.1随机端口，返回一次模型JSON；不执行任何工具。验证程序结束后只停止自己的临时进程。`verify_dispatch.cjs` 随后通过临时V2应用，将模型指令交给已有只读检索/阅读工具验证，正式专家不被替换。

## 安装依据

- [Unsloth Windows 安装与 RTX 3060 示例](https://unsloth.ai/docs/get-started/install/windows-installation)
- [Qwen3-0.6B 官方原始权重与关闭 Thinking 的模板参数](https://huggingface.co/Qwen/Qwen3-0.6B)
- [官方 PyTorch cu130 包索引](https://download.pytorch.org/whl/cu130/torch/)

Windows torchao从PyPI先安装，再安装固定CUDA组合。自动选择最新版曾下载损坏，日志保留，未改全局Python或CUDA驱动。

Triton编译缓存在系统临时目录的 `xhj-retrieval-lora-20261020` 下使用英文路径，避免Windows原生扩展读取中文环境变量失败。训练文件和权重仍在项目独立实验目录。torchao在当前Transformers中被标记为不可用，但本轮是非量化LoRA、不使用torchao量化，Unsloth明确跳过它；实际CUDA训练已通过，不据此宣称量化功能可用。

当前实测：训练48条、36步、约71.5秒；PyTorch峰值保留显存1634MiB，整卡采样峰值2881MiB（含桌面与其他程序）。LoRA为20,236,472字节。测试16条：0.6B原版协议合法0%、微调100%；搜索资料类型0/14→12/14；完整指令0/16→9/16。平均耗时2.57秒→4.06秒，未加速。原版1.7B同题类型8/14、完整4/16、协议75%、平均3.21秒；尚未对1.7B训练。三者均JSON语法100%，必须区别于协议合法。

有明确型号的11题三者均提取正确；0.6B LoRA有芯片的3题只对2题，四段版本号那1题仍漏提。总体字段分数同时包含“没有该字段时不编造”的能力，不能拿大量空字段的正确率宣称已掌握版本。

结果及局限见 `docs/v2/reports/2026-10-20-retrieval-lora-local.md`。不自动增加轮数，不用测试错误修改标签后重报成绩。
